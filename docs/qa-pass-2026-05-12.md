## Bugs fixed in this pass

### 1. SECURITY — admin gate missing on `/api/admin/combined-shadow-diff`
**Severity**: HIGH (information leak)
**File**: [server.js:1797](server.js:1797)
**Reproduction**: `curl -H 'Cookie: starbhai_session=<any-non-admin>' https://stock-platform-gamma.vercel.app/api/admin/combined-shadow-diff` returned 200 with the full V1/V2 scoring shadow-diff store. The route was behind the global session gate at [server.js:583](server.js:583) but did not check `isAdmin` like its sibling `/api/admin/users` at [server.js:1712](server.js:1712).
**Fix**: Added the four-line admin gate (AUTH_ENABLED → sub → userStore.read → isAdmin) mirroring `/api/admin/users`.
**Verification**: `curl http://localhost:3038/api/admin/combined-shadow-diff` now returns `401 {"error":"auth-disabled"}` locally; in prod with AUTH_ENABLED=true, the flow continues to the isAdmin check → 403 for non-admins.

### 2. UX — `/api/sws-stock/:ticker` rejects `.NS`/`.BO` suffixes (quick-win 3)
**Severity**: MEDIUM (user frustration — common copy/paste path)
**File**: [server.js:5720](server.js:5720)
**Reproduction**: `curl http://localhost:3038/api/sws-stock/STAR.NS` → `400 invalid_ticker`. `STAR` (bare) → 200. Frustrating when copying a symbol from `/api/stock/:symbol` responses (which return `.NS`) or from the Buy Now scanner.
**Fix**: Added `.replace(/\.(NS|BO)$/, "")` before the regex validation. Tickers that don't match the ALPHANUM&- regex still return 400 (`FOO!BAR`, `X.IN` confirmed).
**Verification**: `STAR`, `STAR.NS`, `RELIANCE.NS`, `TCS.BO` all return 200 with the bare-symbol record.

### 3. UX — SWS modal scroll position lost on close+reopen (quick-win 5)
**Severity**: LOW (UX nicety, but high-frequency on chip-nav users)
**File**: [gated/app.js:8708-8763](gated/app.js:8708)
**Reproduction**: Open SWS modal for JSLL → scroll down to "Recent news" → close → reopen JSLL → modal jumped back to top.
**Fix**: Per-ticker scroll memory in a bounded Map (≤50 entries; oldest evicted). Crucially the scroll container is **`#swsModalBackdrop`** (overflow:auto), NOT `#swsModalBody` (overflow:visible) — the followup-prompts hint pointed at the wrong element. Restore is gated on `requestAnimationFrame` so layout settles before the `scrollTop` assignment.
**Verification**: in-browser eval — set `backdrop.scrollTop = 400`, close, reopen → `scrollTop` restored to `341.5` (clamped to current `scrollHeight`).

## Bugs logged for follow-up

See [followup-prompts.md](docs/followup-prompts.md) for the previously triaged backlog. This pass adds the following findings:

### NEW-1. `/api/track/stats` is 460× slower in prod (p50 919ms vs 2ms local)
The endpoint returns 338 bytes but takes nearly a second in prod. Local is 2ms because the trade log is empty. In prod the trade log has 569KB of history. The handler likely re-aggregates from a KV scan on every request. Suggested: cache the aggregate (or compute it inside the snapshot-track-record cron and store as a single KV key).

### NEW-2. Local gated SPA serves uncompressed app.js (530 KB vs 124 KB prod)
The local Express server doesn't gzip; Vercel does. For dev parity, add `compression` middleware (one line). Doesn't affect prod, but makes local network-tab inspection misleading.

### NEW-3. Inconsistent admin-tab hardening: `usersTabBtn` only `hidden=true`, `earningsTabBtn` fully removed from DOM
[gated/earnings.js:1018](gated/earnings.js:1018) actively removes `#earningsTabBtn` when `__starbhai_isAdmin !== true`. `gated/app.js` only flips `hidden` on `#usersTabBtn`. Either both should remove or both should hide — pick one. Removing is harder to bypass via devtools, but the admin-route gate at server.js:1712 is the real defense.

### NEW-4. Governance fixture missing locally
There is no `governance.json` at the project root locally. `/api/governance/status` returns `{count:0, source:"empty"}` and every `/api/governance/:symbol` returns 404 by design. Either run `scripts/refresh-governance.mjs` locally or document that the feature requires a prior governance refresh.

### NEW-5. Fundamentals + Surveillance snapshots 19 days stale locally
`fundamentals.generatedAt: 2026-04-23` and `surveillance.fetchedAt: 2026-04-23` (vs today 2026-05-12). Compounds the absence of a staleness banner (issue 2.9). Defensive UI banner remains TBD; the data refresh is operational.

### NEW-6. `starbhai.com` is NOT the Vercel deployment
`https://starbhai.com` 301-redirects to `https://www.starbhai.com` which serves a separate WordPress site. The platform's prod alias is `https://stock-platform-gamma.vercel.app`. Anyone hitting `starbhai.com` expecting the stock platform will land on the wrong site. Either point starbhai.com at the Vercel deployment via a custom domain, or update internal docs/links.

### NEW-7. SWS modal followup-prompts.md hint pointed at the wrong scroll element
Issue 5 in the quick-wins block said `swsModalBody.scrollTop`, but the actual scroll container is `swsModalBackdrop`. Updated in fix #3 above; future modal-related fixes should target `swsModalBackdrop` for scroll behavior.
